# Application Features

Summary of core features implemented in the SaaS Pricing Comparison Page.

## Feature Overview

- **3 Tier Pricing Comparison**: Starter, Pro (Most Popular), and Enterprise.
- **Glassmorphic Aesthetic System**: Frosted glass backdrop blur, ambient glowing spheres, subtle borders, luminous highlight states.
- **Dynamic Billing Cycle Toggle**: Instant switching between Monthly and Annual billing with 20% discount savings.
- **Smooth Price Animations**: Fading numerical transition when toggling billing cycles.
- **Adaptive Flexbox Grid**: Mobile stack layout (`<= 767px`) and desktop side-by-side row (`>= 768px`).
- **Equal Height & Bottom-Aligned CTAs**: `margin-top: auto` anchors action buttons to the card bottom.
- **High Accessibility**: Focus outlines, `aria-label` attributes, high contrast ratio, and semantic HTML5 tag hierarchy.
