# Changelog

All notable technical updates to this project are documented in this file.

## [1.0.0] - 2026-08-15

### Added
- Semantic HTML5 document markup with header, section, article, ul, li, and button elements.
- CSS Glassmorphism design tokens and mobile-first Flexbox responsive layout rules.
- Vanilla JavaScript event handler for dynamic monthly and annual price updates.
- Highlighted `.pricing-card--popular` modifier class with visual "Most Popular" badge.
- Render static deployment manifest (`render.yaml`).
- Complete practical documentation suite inside `docs/`.
